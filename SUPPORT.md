# Support

Use the GitHub issue forms for reproducible bugs and feature proposals.

Before filing a bug:

1. Check the latest release or default branch.
2. Re-run the failing action and capture the exact error.
3. Remove transcripts, audio, usernames, paths, hostnames, credentials, and other private data from logs.
4. Include the macOS version, MeetScribe version or commit, trigger, agent, and destination involved.

General setup questions are welcome as issues when the documentation does not answer them. Security reports must follow [SECURITY.md](SECURITY.md).
