Privacy is a system boundary

Nothing leaves the Mac until you configure it

  • Local by default. Capture and transcription run on your Mac.
  • Explicit agents. Full transcripts reach an agent only after opt-in.
  • Explicit destinations. Git and SFTP are disabled until configured.
  • No credential store. SFTP reuses OpenSSH keys, agent, and host verification.
  • Audio is separate. Remote audio export is off by default.

Build it locally

Three commands to a signed development app

git clone https://github.com/alejacre/meetscribe.git
cd meetscribe
./build.sh

Requires macOS 15 or later, Apple Silicon, Xcode 16 or later, Swift 6, and an existing verified uv installation.
